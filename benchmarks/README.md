# 基准种子集

**这是可复现性资产，不是缓存。** 改动必须说明原因并记录在 `../docs/`。

## 计划的内容

| 文件 | 用途 |
|---|---|
| `seeds-v1.txt` | 日常种子集，约 100 局。每次算法改动都跑 |
| `seeds-1000-v1.txt` | 验收种子集，1000 局。只在里程碑验收时跑 |

格式待定（一行一个种子，或一行一个"游戏编号"——参考 macroxue 的 `-i 1000 2001` 机制）。

## 约束

- 每个种子集有**版本号**；所有跑批结果都要带版本号。
- **不同规则集或不同种子集下的分数禁止混排对比。**
- 引擎规则变更（`RulesetVersion()` 提升）必须重建种子集基线。
- 跑批产生的中间数据放 `raw/`（已被 `.gitignore` 忽略），只有种子集本身进版本管理。
