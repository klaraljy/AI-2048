# 与 JS 参考原型的差异记录

> **状态：空。** 目前还没有 C++ 实现，所以还没有差异。

## 这份文件为什么存在

本项目的价值建立在「AI 跑的就是真实规则」之上。参考原型里规则漂移已经真实发生过
（`worker-pool.js` 的 `LocalGameSimulator` 长出了第二套规则，与 `game.js` 不一致，
导致调参结论不可信）。

## 要记什么

C++ 版与 JS 原型行为不一致时，**逐条**记录在这里，并说明是「照抄」还是「改对」。

已知必须处理的一条（来自代码审查）：

- 原型的 `tableScore` 把空格在行、列上各计一次，等于空格的有效权重被放大到约
  `2×260 + 360 ≈ 880`（残局 1240），而不是 `config.js` 里写的 360。
  **当 C++ 版分数低于 JS 版时，必须先排除「是不是把 bug 一起改了」这个解释。**

其它已发现的原型缺陷（是否照抄待定）：

| # | 原型行为 | 问题 |
|---|---|---|
| 1 | `bitboard.js` 把 exponent clamp 到 15 | 编码 65536 被静默写成 32768；两个 32768 相撞也合不出 65536 → AI 模拟规则 ≠ 现实规则 |
| 2 | `ai-core.js` 的 chance node 采样后把概率归一化成 `1/sampled.length` | 不是真实概率 → 期望值有偏，偏保守 |
| 3 | TT 的 `evict()` 是 O(n) 线性扫描全表只删一条 | 表打满后每次插入都扫 40 万条，性能悬崖 |
| 4 | `main.js` 每步都重发 `configure`，重建 `UltimateAI` | `keepCache: true` 的跨步缓存复用完全失效 |
| 5 | `getBestMoveFromBitboard` 的迭代加深在实战并行路径没生效 | `evaluateRootDirection` 是单次固定深度搜索 |
